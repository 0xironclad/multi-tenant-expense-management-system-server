# AWS Infrastructure

Manual/console-provisioned AWS resources for production, with the config files
needed to reproduce them via the AWS CLI.

## S3 — receipt uploads

Private bucket for expense receipts. **All public access is blocked** — objects
are only ever reached through short-lived presigned URLs generated by the file
service. Locally, MinIO stands in for this bucket.

| Setting              | Value                              |
|----------------------|------------------------------------|
| Bucket name          | `expense-app-receipts-cole`    |
| Region               | `eu-central-1` (Frankfurt)         |
| Public access        | Block ALL public access            |
| Versioning           | Enabled                            |
| Encryption           | SSE-S3 (Amazon S3 managed keys)    |
| CORS                 | see `s3-cors.json`                 |
| Lifecycle            | see `s3-lifecycle.json` — Standard → Glacier Instant Retrieval after 365 days |

### Reproduce via CLI

```bash
BUCKET=expense-app-receipts-cole
REGION=eu-central-1

aws s3api create-bucket --bucket "$BUCKET" --region "$REGION" \
  --create-bucket-configuration LocationConstraint="$REGION"

aws s3api put-public-access-block --bucket "$BUCKET" \
  --public-access-block-configuration \
  BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true

aws s3api put-bucket-versioning --bucket "$BUCKET" \
  --versioning-configuration Status=Enabled

aws s3api put-bucket-cors --bucket "$BUCKET" \
  --cors-configuration file://infra/aws/s3-cors.json

aws s3api put-bucket-lifecycle-configuration --bucket "$BUCKET" \
  --lifecycle-configuration file://infra/aws/s3-lifecycle.json
```

### Notes

- Bucket names are globally unique across all AWS accounts — hence the `<suffix>`.
- CORS `AllowedOrigins` is for browser-direct presigned uploads; add the frontend
  URL here once it exists. `http://localhost:3000` (the dev gateway) is fine for now.
- Never make the bucket public — all access goes through presigned URLs.
